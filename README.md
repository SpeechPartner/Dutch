# SpeechPartner.Dutch

Een gratis, offline werkende app (PWA) om Nederlands te gebruiken in gesprekken. Geen account, geen server, geen kosten.

Deze map is een complete app. Zet de **inhoud** van deze map in een eigen GitHub-repository (bijvoorbeeld `Dutch`) en zet GitHub Pages aan.
Webadres: https://speechpartner.github.io/Dutch/
Gebruik niet de repository van de Spaanse app: elke taal heeft zijn eigen repository en zijn eigen webadres.

Stemmen: natuurlijke spraak met Piper (open source, MIT). Stem: Pim (CC0).

Versie 2.5
